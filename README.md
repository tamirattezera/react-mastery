# React Mastery

A practical, architecture-first React learning system focused on building production-oriented products rather than memorizing APIs.

## Objective

Build strong React engineering ability as part of an AI-powered full-stack development stack:

```text
Problem
→ Product
→ Architecture
→ React
→ API
→ Backend
→ Database
→ AI
→ Security
→ Deployment
→ Feedback
→ Iteration
```

The goal is not to master React in isolation, but to use React effectively inside real software systems.

---

## Learning Philosophy

```text
Understand
→ Predict
→ Build
→ Break
→ Debug
→ Refactor
→ Architect
→ Ship
→ Explain
```

Learning depth is based on engineering leverage:

- **Deep:** problem solving, architecture, product thinking, AI integration
- **Strong:** React, JavaScript, TypeScript, backend/API design, SQL
- **Practical:** CSS, tooling, framework details
- **Selective:** React and browser internals when they help explain behavior, debugging, or performance

### Core Rule

```text
REAL PRODUCT NEED
→ REQUIRED CONCEPT
→ MINIMUM THEORY
→ IMPLEMENT
→ DEBUG
→ ARCHITECTURAL DECISION
→ SHIP
```

## Learning Standard

For every important concept, the goal is to answer:

1. What problem does it solve?
2. Why does React need it?
3. What is the mental model?
4. How do I use it?
5. What happens when it breaks?
6. How do I debug it?
7. Where does it belong architecturally?
8. When should I **not** use it?

The target is not API memorization.

The target is **engineering judgment**.
